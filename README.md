# PHYSICS Computation repository

To contain a series of ipynb files for use in physics courses at Penn State

General guidelines when using Google Colab: Gemini AI assist is enabled; students should use it for debugging after trying their own code. Note that AI may try to auto-fill, but it is not always correct.
